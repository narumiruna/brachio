# Change notes

Package `brachio` uses `Cargo.toml` as its version source for crates.io and PyPI.

Read [the change-note policy and commands](../docs/publishing.md#change-notes) before adding a note or preparing a release.
Run `changenote status` after adding or changing notes.

Keep pending notes in this directory.
Do not create empty notes or edit generated release files by hand.
`changenote version` consumes notes only during an authorized release.
